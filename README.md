# United Crypto Alliance (UCA) - Official Website

Official website and information portal for **United Crypto Alliance** (UCA) and the **UCAT** mobile token mining ecosystem.

## 🚀 Overview
United Crypto Alliance is a decentralized mobile mining alliance enabling users worldwide to participate in 24-hour cloud proof-of-presence sessions with zero battery drain and non-custodial crypto wallet security.

## 🌟 Key Features
- **Zero Battery & Hardware Drain**: Energy-efficient cloud consensus.
- **Concurrent Referral Overlap Boost**: Earn +0.05 UCAT/hr per direct active peer mining simultaneously with no caps.
- **Non-Custodial Web3 Wallet**: Embedded decentralized wallet support.
- **Interactive Mining Calculator**: Real-time simulation of hourly, daily, and monthly earnings.
- **Google Play & Store Policy Compliance**: Comprehensive Privacy Policy and Terms of Service.
